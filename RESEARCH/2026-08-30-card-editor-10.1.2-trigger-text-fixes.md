# Card Editor 10.1.2 trigger and text fixes

Date: 2026-08-30
Target: Slay the Spire 2 public beta v0.111.0

## 1. Reduce Cost -> This Card -> Whenever (Event)

**Hypothesis:** The event hooks were not dispatching the configured cost reduction.

**Result:** False. Direct event dispatch already worked. A new test that installs the same
`CardEditorExtraEffectPower` produced by the editor reproduced the failure on the first
`Played` event.

**Root cause:** `ApplyTriggeredCardCostsLess` cloned the power-routed definition into its
resulting passive grant but retained `AsPower = true`. The cost calculator intentionally
ignores power definitions, so the created grant had no effect.

**Fix:** Clear `AsPower` on the resulting passive grant. The regression test now installs
the power and verifies all supported Whenever events.

## 2. Match Energy rendered twice

**Hypothesis:** The editor registered the Match Energy option twice.

**Result:** False. The option is registered once. The generated card text formatter applied
the same cost qualifier while building a selection descriptor and again while formatting
the completed sentence. The two passes used differently-colored energy icons, so a direct
string comparison could not identify the duplicate.

**Fix:** Make cost/name filter formatting idempotent and compare the localized text around
the variable energy-icon markup. The reproduced `Move 2 random cards costing exactly ...`
line now contains one `costing exactly` qualifier.

## 3. Resources -> After Death -> Check on Power

**Hypothesis:** The After Death hook was absent.

**Result:** False. The hook and power lifecycle dispatch were present. Card-owner effects
defaulted `Trigger From` to `Self`, which meant they waited for the player holding the power
to die even though the generated text said the player sees a creature die.

**Fix:** Normalize only card-owner After Death effects with the legacy/default `Self` value
to `Anyone`. Explicit Self behavior remains unchanged for effects attached to enemy or
effect targets.
