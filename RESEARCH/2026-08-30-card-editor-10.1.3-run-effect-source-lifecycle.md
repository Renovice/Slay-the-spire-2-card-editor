# Card Editor 10.1.3 Run Effect Source lifecycle fixes

Date: 2026-08-30
Target: Slay the Spire 2 public beta v0.111.0

## Hypothesis 1: the selected cards' OnPlay methods do not run

**Result:** False.

The headless beta harness executed the real `Run Effect Source` path with the editor's
default amount of zero. Particle Wall and I Am Invincible applied their canonical Block,
and Right Hand Hand dealt damage when the owner had Osty and the host card supplied an
enemy target.

## Hypothesis 2: non-OnPlay card behavior is dropped

**Result:** True.

`RunSingleEffectSourceOnPlay` invokes only the borrowed card's protected `OnPlay` method.
The reported cards put their second printed behavior in other vanilla lifecycle methods:

- Particle Wall overrides `GetResultLocationForCardPlay` to replace a normal Discard result with Hand.
- Right Hand Hand overrides `AfterCardPlayedLate` to return itself from Discard when its owner plays a card costing at least 2 Energy.
- I Am Invincible overrides `AfterAutoPostPlayPhaseEntered` to auto-play itself when it is on top of its owner's Draw Pile.

Because the borrowed source object is not the host card and is not in a combat pile, vanilla
hook iteration cannot apply those methods to the host automatically.

## Fix

- Forward Particle Wall's result-pile behavior during `Hook.ModifyCardPlayResultLocation`,
  preserving Exhaust, Power/dupe removal, and earlier non-Discard results.
- Forward Right Hand Hand's late card-play behavior after vanilla `Hook.AfterCardPlayed`.
- Forward I Am Invincible's top-of-draw behavior after vanilla
  `Hook.AfterAutoPostPlayPhaseEntered`, using `CardPileCmd.AutoPlayFromDrawPile`.
- Apply these lifecycle behaviors only to immediate, card-hosted, unfiltered OnPlay
  `Run Effect Source` rows. Power, grant-payload, scheduled, and keyword-filtered rows do
  not silently gain permanent passive behavior.

## Verification

- Public-beta v0.111.0 compilation: no compiler warnings or errors.
- Headless beta suite: 15/15 passed, 2,187 beta and mod models loaded.
- Particle Wall's result-pile decision and Right Hand Hand's actual Discard-to-Hand move
  execute in the headless harness.
- I Am Invincible's exact top-card eligibility is headless-tested; the production path uses
  the current beta's `CardPileCmd.AutoPlayFromDrawPile`. The full card-play wrapper requires
  Godot's native runtime, so visual/engine execution remains a separate in-game check.
