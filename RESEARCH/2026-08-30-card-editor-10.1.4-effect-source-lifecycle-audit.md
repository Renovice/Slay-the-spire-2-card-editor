# Card Editor 10.1.4 Effect Source lifecycle audit

Date: 2026-08-30
Target: Slay the Spire 2 public beta v0.111.0

## Hypothesis 1: the remaining audited cards already inherit their complete behavior

**Result:** False.

The immediate `OnPlay` payload worked, but the host did not receive behavior implemented in
draw, Exhaust, card-play, phase, or result-location callbacks. Confirmed affected sources were:

- Banshee's Cry
- Drum of Battle
- Howl From Beyond
- Kingly Kick
- Kingly Punch
- Make It So
- Midnight
- Pinpoint
- Shining Strike
- The Ball
- Void

## Hypothesis 2: one generic callback forwarder is safe

**Result:** False.

Vanilla callbacks frequently compare the event card with `this`, mutate private state on the
source instance, inspect the source's physical pile, or move the source card itself. Invoking
every callback against a detached source object would either do nothing or move/mutate the
wrong card. The fix therefore maps each printed behavior to the host while retaining the
persistent source object where source-owned state matters.

## Hypothesis 3: borrowed mutable source state survives between events and plays

**Result:** False before the fix; true after the fix.

The draw callback could resolve a different runtime source instance from the one used by
`OnPlay`. This made Kingly Punch remain at its original damage after the host was drawn.
Lifecycle resolution now reuses the persistent source instances in occurrence order.

## Implemented parity

- Shining Strike: normal Discard result becomes top of Draw Pile.
- The Ball: in multiplayer, normal Discard result transfers to a random living teammate's
  Draw Pile at a random position.
- Kingly Kick: host cost decreases when drawn.
- Kingly Punch: persistent borrowed damage increases when the host is drawn.
- Void: owner loses Energy when the host is drawn.
- Drum of Battle: owner gains its configured Energy when the host is Exhausted.
- Midnight: host cost decreases whenever any card is Exhausted and initializes from combat history.
- Banshee's Cry: host cost tracks Ethereal cards played this combat and initializes from history.
- Pinpoint: host cost tracks Skills played this turn and initializes from history.
- Make It So: host returns to Hand on each configured Skill threshold.
- Howl From Beyond: an eligible host auto-plays from the Exhaust Pile during the vanilla phase.

## Verification

- Beta headless suite: 18/18 passed, with 2,187 beta and mod models loaded.
- The suite covers all eleven audited sources and retains the earlier three-card coverage.
- The Ball uses a real two-player headless combat and verifies recipient, pile, and position.
- Kingly Punch executes before and after a draw event and verifies increased real damage.
- Full Howl From Beyond auto-play enters Godot-native timing code, which is not safe in the
  plain .NET harness. Its immediate damage and exact Exhaust-pile eligibility are covered;
  final wrapper execution remains an engine/in-game verification boundary.
- The installed Steam game was v0.107.1 during this audit, so engine testing was not run
  against that incompatible executable. Builds and headless tests used the repository's
  tracked v0.111.0 beta references.
